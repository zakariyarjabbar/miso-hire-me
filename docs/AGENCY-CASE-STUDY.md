# Miso — a very employable cat

Miso is a self-initiated agency portfolio concept: a complete personal “Hire Me” website whose sole owner is a fictional freelance cat. The creative challenge was to make ordinary cat behavior feel like credible specialist work while keeping every interaction clear and usable.

We established a consistent adult ginger tabby and generated eleven reference-guided photographs across one sunny home studio. A powder-blue hero, full-body cutout, confident Bricolage Grotesque headlines and restrained tomato accents introduce the character immediately. Hanken Grotesk carries the quieter reading and form surfaces. The same identity extends through photographic case studies, a printable résumé, social covers and downloadable hire cards.

The writing treats the cat's work with calm professional seriousness. Keyboard occupancy becomes a productivity initiative. An empty box becomes a quality-assurance engagement. References come from furniture, keeping the parody unmistakable without adding a disclaimer to every joke.

The website includes a scripted interview and a matching sleep/wake portrait interaction. Its main journey is a three-step fictional offer builder. A deterministic set of service, duration, sunshine and box-retention rules accepts an offer or explains exact counterterms. Visitors can negotiate, edit, withdraw, revisit browser-local history and export a personalized PNG souvenir.

The implementation uses Next.js App Router and strict TypeScript with a portable static export. All visitor records stay in browser storage. Storage validation, explicit temporary-session recovery and scoped reset make those boundaries visible without adding a backend or collecting contact details. The résumé is a real PDF, and card downloads are rendered with local photography and fonts.

Verification includes offer/storage tests, production-browser interaction and download checks, direct static navigation, metadata associations, responsive captures, automated accessibility checks and visual export inspection. See QA.md for recorded results and limits.

This is a fictional portfolio demonstration, not a live animal-hire business. No audience, revenue, conversion, engagement or client outcomes have been measured or claimed.
